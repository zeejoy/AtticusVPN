项目只使用标准 WireGuard 和上游成熟密码学；不提供匿名、不可检测或绕过网络管控的承诺。
运营商可能观察端点、时序、流量大小和协议特征。自托管只改变出口位置，不会消除所有元数据。

每个设备使用独立 Peer。设备遗失或配置泄露后，应禁用/删除对应 Peer 并重新生成凭据。
切勿上传真实配置、二维码、Token、密码、证书私钥或签名密钥。
公开测试夹具严禁用于部署。公开构建的调试 APK 不等同于经过长稳审计的生产版本。

报告安全问题时先通过你选定的项目维护者私密渠道联系；本仓库不预置个人邮箱。
公开 Issue 仅提交已脱敏的复现步骤，不贴原始日志或配置。不要把漏洞报告直接变成凭据泄露。
