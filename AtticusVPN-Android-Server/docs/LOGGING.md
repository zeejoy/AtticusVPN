# 正式版 0.6.0 运行日志 · TianzeL

设置 → 本次运行日志。日志从本次应用进程启动起记录；后台服务继续运行时持续采样。进程结束后未保存日志丢失，不自动持久化或上传。

使用测试版既有有界模型及页面，正式版采集器只接入 WireGuard。页面与原生状态每秒更新，受系统后台调度影响；显示最后采样时间。记录实际 UDP 对端 IP/端口、分配地址、最近握手、观察时长和服务端视角的收发字节。最近 180 秒握手推断活跃，WireGuard 没有连续认证会话，不能把观察时长称为精确连接时间。断开设备、已观察地址变化和最后计数保留；失败读数不把旧设备误判断开。

默认隐藏部分 IP，临时手动显示后复制/保存也使用该显示版本；重新打开恢复遮盖。两种操作冻结同一份当前快照。FLAG_SECURE 防截图，Android 13+ 剪贴板标注敏感，SAF 保存 TXT；待导出快照仅内存保留 60 秒。完整 IP 仍属私密信息，外部文件提供商可能同步备份。

最多 1024 条设备记录、512 个事件、每设备 16 个历史端点，输出最多 192 KiB；超限显示省略提示。只记录固定错误类别与已知原因；不确定的原因明确标记。不会收集私钥、PSK、DDNS 凭据、完整配置、原始异常、访问目标或系统 Logcat。

统计是观察结果，不等于计费流量；采样间崩溃可丢失最后一小段数据。日志文本正文保留技术双语，界面控件提供 13 种语言。本次没有增加公网日志服务。

完整 IP 在进程内保留，默认遮盖仅是显示/导出策略，不代表不收集或匿名化。VPN 停止但进程仍存活时，本次记录保留。剪贴板和系统文件提供商生成的外部副本不随进程结束删除，可能按用户的系统/云端设置同步。主隐私入口见 [PRIVACY.md](../PRIVACY.md)。

网关使用与 WireGuard 相同的有界错误计数器：TCP/UDP 外连失败、外连建立超时、转发端点失败、TCP/UDP 配额拒绝、DNS 全部上游失败和异常转发读写。正常 EOF、主动取消及设计中的空闲回收不作为转发失败。仅保存固定码、固定解释、首次/末次时间及次数；不保存原始异常、目标或 DNS 查询名。
