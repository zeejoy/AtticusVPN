- F03：分别传播两个方向的 FIN，保留反向响应；取消/异常关闭并等待两个复制协程结束。

## 原 0.6.0 开发记录

2026-11-02 至 2026-11-03（香港时间）。从实际 GitHub main 5af69e4（版本 0.5.8 / code 19）建立独立 release/0.6.0 分支；TEST 1.3.1 工作目录保留。

采用正式版 MainActivity 和现有保存/撤销/导出事务为基础，迁入测试版主页布局；DDNS/DNS/端口/MTU 原表单以 VpnSettingsActivity 复用。保留正式版现有撤销失败停止服务、安全密钥清理和 revoked-peer 生命周期测试。没有整体覆盖正式版 service/native-engine。

HomePageNavigation、HomePagesView、PageMotion、GlassPixels、GlassOptics、HomeWindowInsets 六个文件精确取自 TEST 1.3.0，SHA-256 见 GLASS-PROVENANCE.json。自绘设置图标与 13 种语言来自 TEST 1.3.1。删除未使用协议 UI 字符串，原导航 PNG 迁入 artwork/legacy-navigation 保留来源。285 项字符串在各语言保持一致；补译正式基线独有的撤销失败停止提示。

运行日志复用测试版有界模型、敏感快照生命周期、页面和按需呈现机制，采集器只连接 WG。原生移入数字 UDP 对端规范化、有界固定错误分类和完整读数标志；不引入 ALP/QUIC/DTLS/strongSwan 服务。若读数失败，仅记录固定错误，保留旧观察记录。停止前做最后一次采样；每次引擎重启增加观察代号，避免同秒重启合并观察时段。

锁屏引导使用 Android 标准通知/电池授权；延续 CPU 限时锁并提前续租。为每秒日志采样复用测试版设备行局部刷新与通知文字去重，避免增加无意义界面/通知刷新。没有增加后台自启动或隐式 Root 请求。

正式 0.6.0 / versionCode 20；Stable 应用标签、-stable 版本后缀、STABLE 文件名；独立 .debug 应用标签 TEST、-test-debug 版本后缀、TEST 文件名。0.5.8 为第一正式版，原 1.x 均标记为 TEST。原签名由用户保管，交付明确区分待原签名正式包与调试测试包。

构建中发现原签名未知、旧导航资源未使用、测试侧预览参数未透传等情况：签名改为本地原密钥工具；未使用运行资源删除但历史图片保留；Gradle 明确透传预览参数。未关闭 Lint 规则或改写现有认证格式来通过检查。签名策略测试验证包名、版本递增和证书一致性，合成密钥测试只在临时目录运行，结束即清理。

所有结果见 VERIFICATION.md 和 validation-results.json。Go/race/vet、四 ABI 和 Android 构建在 Linux 执行；未完成真实手机验收，不宣称已验证真实原签名或升级数据保留。
