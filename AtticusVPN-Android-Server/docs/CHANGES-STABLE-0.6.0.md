本次修订编号 P1-20261103，按用户要求覆盖同版本交付文件；以新的 SHA256SUMS 核对文件，不将它误认成先前未修复的构建。配置 schema、WireGuard 认证/导出格式、包名和 versionCode 均保持不变。

- F01：通过 AtomicFile 恢复读取后再判断是否首次安装；识别 .bak/.new/异常路径，恢复或解密失败时保留数据并报错，不生成替代身份。
- F02：TCP 同时计入待拨号和已建立连接，全局 512、每 WireGuard Peer 64；IPv4/IPv6 共用同一 Peer 配额。两端无数据 15 分钟关闭，半关闭后剩余方向无数据 2 分钟关闭；持续传输会续期。失败、停止和撤销引起的引擎关闭回收 socket 与配额。
- F03：分别传播两个方向的 FIN，保留反向响应；取消/异常关闭并等待两个复制协程结束。

独立下载云盘 TEST 1.3.2 源码检查：F01 同样存在，API 28/35 回归复现；其既有 TCP 配额、半关闭及真实 WireGuard 半关闭响应测试通过。测试版本次只检查，未修改或重新发布。

完整说明见 [P1 修复记录](P1-FIX-2026-11-03.md)。本次只修三个 P1；原审查 F04–F09、依赖维护及原签名/真机验证仍需后续处理，不宣称已完成全部开源前整改。

## 原 0.6.0 开发记录

以 GitHub 0.5.8 / 5af69e4 为基础。复用 TEST 1.3.1 的语言、设置图标和日志；液态玻璃、滑块与分页组件固定使用 TEST 1.3.0 / e934d48，六个文件逐字节来源见 GLASS-PROVENANCE.json。

- 新主页状态卡片、流量/设备摘要、纵向启停按钮，底部为主页、设备、IP 信息。DDNS、DNS、端口和 MTU 移到设置 → VPN 设置；保留正式版校验和原子保存流程。
- 设置六个入口增加图标。共 13 种离线语言，支持阿拉伯语 RTL；部分长译文为机器辅助，尚待母语审校。
- 本次运行日志记录 WireGuard 实际 UDP 对端、握手、观察时长、收发计数、网络/DDNS/固定错误及原因。默认遮盖 IP，断开记录保留，复制/保存同一快照，页面禁止截屏。只在查看时生成日志文本。
- 锁屏后台运行页面引导通知权限、电池优化豁免及厂商后台开关；用户确认系统弹窗。既有有限时唤醒锁提前续租，不能保证系统强行停止后恢复。
- 复用原生遥测的数字端点校验、失败读数可用性标志和有界错误计数；统计失败保留旧设备信息，不伪造断开。没有迁入测试版其他网络协议或完整数据面修改。

保留 0.5.8 的设备撤销/密钥清理、安全导出、标准 WireGuard `.conf` 与二维码、加密状态格式。后台每秒采样；设备卡片复用并仅在设备页刷新，通知只在显示内容变化时更新。

新旧 APK 的原签名一致性需要在用户保管密钥的电脑执行签名工具核验。真机升级、锁屏、读屏、GPU 材质表现、跨网 IPv6 和持续多设备流量仍待验收。
