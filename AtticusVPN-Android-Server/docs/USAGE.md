## 网络准备

服务端手机必须取得健康的公网 IPv6，客户端网络也需有 IPv6；没有第三方中继帮助 IPv4-only 客户端连接 IPv6-only 入口。
Wi-Fi 下检查路由器 IPv6 防火墙允许目标手机 UDP 51820，或你配置的实际端口。移动网络是否允许入站由运营商决定。
只观察到公网 IPv6 不证明端口可达。请用不同网络做握手验证，不要以同一 Wi-Fi 结果代替。

## 三页

首页是运行信息、启停和重测；第二页是 Peer 管理；第三页是连接及 DDNS。切页不保存表单。
右上角设置可选择三种语言和外观。默认英语、跟随系统；语言入口按当前语言显示 Language/语言、Language/語言 或 Language。

## 连接设置

域名或公网 IPv6 不加方括号/协议前缀；留空时优先用开启的 DDNS 域名，否则用当前公网 IPv6。
端口合法范围 1–65535，默认 51820；MTU 1280–1420，默认 1380。
更改端口后同步路由器及客户端 Endpoint；旧导出文件不会自动更新。
内置 DNS 默认使用网络提供的上游，也可以填写数字 IP 自定义上游。关闭内置 DNS 后，客户端需要配置可达的 DNS。

## DDNS（可选）

先在对应服务商申请/准备域名与授权；应用不会自动注册域名。
关闭时只有服务商选择；已保存的开启服务商进入时直接显示对应字段。说明在输入框上方。

| 服务商 | 必需/显示字段 |
|---|---|
| DuckDNS | 域名或 subdomain、Token |
| Cloudflare | 完整域名、DNS 编辑 API Token、Zone ID、已有记录的 Record ID；记录为 AAAA、仅 DNS |
| No-IP | 完整域名、账户/邮箱或 DDNS Key 用户名、对应密码 |
| Dynu | 完整域名、用户名、更新密码 |
| FreeDNS | 完整域名、该记录的 update key，不是整条更新 URL |
| 自定义 | 完整域名、HTTPS GET URL、按接口需要提供的可选 Token |

自定义 URL 必须含 `{ipv6}`，可含 `{hostname}`、`{token}`。只使用可信服务。
切换不自动保存/联网；主动保存只校验当前可见 DDNS 字段，隐藏草稿不会阻止保存。同服务商下凭据留空保留已保存值，切换服务商需新的对应凭据。
DDNS 与服务端运行生命周期一起工作：地址变化去抖后更新，默认事件请求至少间隔一分钟，低频一致性更新六小时。
“已更新”只表示服务商接受请求；“已验证”表示当前系统 AAAA 查询与目标 IPv6 一致，不证明 VPN 可达。客户端可能缓存旧地址，DNS 生效后可能需要断开重连。

## Peer 与导出

启动服务端后添加名称合法、不重复的 Peer；每台设备独立配置。
导出页可显示二维码、保存相册、保存 .conf 或复制配置；包含私钥，请按界面警告保管。
导出选项只影响本次导出，不增加服务端尚未提供的 IPv6 互联网转发能力。
确认导出成功及实际握手后可以 Seal，删除服务端可导出的客户端私钥；已有客户端仍能连接，但不能再取回原私钥。

## 验收与排错

客户端导入后检查最新握手与双向流量，再检查 DNS 和实际网页。首页四站成功仅证明手机出口，不是客户端验收，也不是测速。
无握手时核对域名 AAAA、双方端口、客户端 IPv6、入站规则；有握手但无网页时检查上游 DNS、路由、MTU 和服务端出口。
速度取决于服务端上传、两端链路/丢包、手机 CPU/温度及用户态转发开销。不要用扩大权限或关闭安全校验代替排错。


## 0.6.0 修复后的连接与发布边界

TCP 默认全局 512、每设备 64 条；达到上限时新的连接会被拒绝，已有连接继续运行。15 分钟无流量回收，半关闭后 2 分钟无流量回收，持续传输会续期。设置中的日志记录固定网关错误类别，正常关闭不作为连接故障。日志默认遮盖仅是显示策略，完整 IP 仍在本次进程内存中；见 LOGGING.md 与 PRIVACY.md。

UNSIGNED Release 必须用旧正式版相同的本地签名密钥签名再覆盖安装，不能用 Debug 包代替，不要先卸载或清空数据。该交付未进行真实手机验收；详见完整修复报告。
