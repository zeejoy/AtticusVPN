## 源码中的测试数据

测试含明确公开的 TEST ONLY CA、客户端 PKCS#12 和固定测试密码，以及重复字节/运行时随机生成的 WireGuard 测试密钥。
这些不是部署凭据，但公开测试私钥也不能用于真实服务或设备；绝对不要安装测试 CA 到真实设备。
示例域名使用保留的 example/test 域或明示离线模拟的 DDNS 测试域，不应当作实际部署地址。

## 应用运行

- 没有项目云服务、广告或分析 SDK。
- 密钥、Peer 和 DDNS 设置在应用私有加密存储中；不允许应用备份。
- DDNS 提供商会接收域名、公网 IPv6 和其所需授权信息；DNS-only DDNS 不转发 VPN 流量。
- 四站网络检查会向所列官网发送固定 HTTPS 请求，网站能看到出口 IP 等普通连接元数据，但请求不附带应用密钥、DDNS Token 或设备标识。
- Root 检查需要用户操作/授权；不自动变更 SELinux、系统安全或防火墙设置。
- 本地导出配置、剪贴板和相册可能被其他应用读取/同步，管理员必须自行保护。

## 本次运行日志

设置中的“本次运行日志”从应用进程启动开始，在进程内记录服务状态、网络类型、监听端口、配置端点、DDNS 状态、设备名称及分配地址、实际对端 IP/端口和历史变化、最近握手、收发字节、采样时间，以及固定错误类别、次数和已知原因。只采集本正式版实际运行的 WireGuard 服务。WireGuard 活跃状态由最近握手推断，观察时长不是精确连接时间，也不是计费数据。

完整 IP 会保留在内存中。默认“隐藏部分 IP”仅影响页面与导出快照的显示，不表示没有收集，也不表示彻底匿名化。用户可临时显示完整 IP；复制与保存均按操作时选择的遮盖状态冻结快照。重新进入日志页恢复遮盖。日志页面启用截图保护，Android 13 及以上为剪贴板设置敏感标记；这些措施不能保证其他软件或接收方不会保存用户主动导出的内容。

内存最多保留 1024 条设备记录、512 个事件和每设备 16 个历史端点；文本快照最多 192 KiB，超限明确显示省略提示。停止 VPN 但进程继续存在时保留本次记录；进程结束后未导出的日志丢失，重新启动形成新记录。后台服务仍在同一进程运行时继续采样，实际刷新受系统调度影响。

用户可复制当前快照，或通过 Android 系统文件选择器保存 TXT。待保存快照仅在内存保留 60 秒。导出后生命周期由用户、剪贴板和所选文件提供商控制；外部应用、系统剪贴板或云盘提供商可能同步、备份这些文件，结束本应用进程不会删除外部副本。

日志不会自动上传、自动持久化到磁盘或读取系统 Logcat。不会记录私钥、PSK、DDNS 凭据、完整 VPN 配置、访问目标、DNS 查询名或原始异常文本。错误只说明已观察到的固定类别，不能据此推断未经确认的远端原因。界面控件支持 13 种语言；技术日志正文保留中英双语，各语言下遮盖和导出行为相同。详细字段与边界见 [docs/LOGGING.md](docs/LOGGING.md)。

## 检查与限制

`tools/verify-public.py` 逐条检查源 ZIP、嵌套 Wrapper JAR 和 PNG 结构，不打印匹配到的凭据值。
它禁止源码包包含 AAR/APK、缓存、签名、日志等；构建后不能把整个工作目录重新压缩发布，应重新按发布白名单整理。
普通扫描无法数学证明任意未知内容没有秘密；实际发布还需人工核对、证书解析、来源审查和最终档案检查。
发布核验记录见 [VERIFICATION.md](VERIFICATION.md)。后续添加文件必须重新审查。
