# Security Policy

## Supported Versions

AtticusVPN is currently under development.

Security reports concerning the current Android Server implementation on the `main` branch are welcome.

Older versions are not guaranteed to receive security updates.

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities or sensitive technical details in GitHub Issues or Discussions.

Once private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** feature to submit a confidential report.

If private reporting is unavailable, you may open a public issue asking for a private contact method, without including vulnerability details, credentials or exploit information.

When reporting, please include:

- A description of the affected component
- The affected application version
- Steps to reproduce, where appropriate
- The potential security impact

Never include real WireGuard private keys, DDNS API tokens, passwords or other sensitive credentials.

## Security Scope

The current release focuses on the AtticusVPN Android Server.

Security-related limitations may still exist, and successful builds or automated tests do not guarantee complete security.

## Disclosure

Please allow the maintainers an opportunity to investigate and address confirmed vulnerabilities before public disclosure.
